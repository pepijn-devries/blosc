# blosc: Compress and Decompress Data Using the 'BLOSC' Library

Arrays of structured data types can require large volumes of disk space
to store. 'Blosc' is a library that provides a fast and efficient way to
compress such data. It is often applied in storage of n-dimensional
arrays, such as in the case of the geo-spatial 'zarr' file format. This
package can be used to compress and decompress data using 'Blosc'.
